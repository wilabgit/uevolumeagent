# Towards trustworthy AI agents for Mobile Core Networks  – Code Repository

- Folder intent-to-agent_results provides the scripts to submit the intent to the agent and to run the experiment, including the obtained results.
- Folder gnb_Oaibox40 contains the configuration used to setup the gNB, and the script to start and stop the gNB.
- The core-mcp_ThinkPad folder contains the scripts used to start and stop the 5G Core, as well as the implementation of the MCP server and the report callback server. The VPP-UPF-based 5G Core implementation is based on the OpenAirInterface repository at the following: https://gitlab.eurecom.fr/oai/cn5g/oai-cn5g-fed/-/tree/e46933923f5f06c817ac284db2b41a07084992fc/. An NGINX reverse proxy is also deployed between the SMF and the report callback server to convert HTTP/2 traffic generated by the SMF into HTTP/1.1 requests supported by the callback server. The NGINX proxy configuration is provided in this folder.
- Folder LangGraph-DeepEval_Jetson contains the agent and evaluator code.
